# Dataset

## Telco Customer Churn Dataset

**Source:** [Kaggle - Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

**Original file:** `WA_Fn-UseC_-Telco-Customer-Churn.csv`

**Dataset size:** 7,043 records and 21 columns.

### Download Instructions

1. Visit the Kaggle dataset link above.
2. Download the dataset.
3. Place the CSV file in this `data/` directory.
4. Run the SQL scripts in the `sql/` directory using PostgreSQL.
